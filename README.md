# Countdown, Guessing Game & Loop Patterns

This assignment practices while loops, for loops, conditionals, and counters in Python.

## Files

- `countdown.py` — Counts down from a number to zero and prints "Blast off!"
- `guess_game.py` — Runs a guessing game with hints and an attempt counter.
- `spell_it_out.py` — Prints each letter of a word and then prints the letters with numbers.
- `screenshots/` — Contains screenshots showing the programs running.

## While Loop vs For Loop

I would use a `while` loop when I want the program to keep repeating until a condition becomes false, such as a guessing game. I would use a `for` loop when I know I need to go through each item in a collection, such as each letter in a word.
